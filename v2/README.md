# 《明末》v2 — 极简内核

天启七年末,信王朱由检入承大统。你是崇祯,从登基第一道大题开始,一刀一刀力挽狂澜。

v2 是对旧架构的重写:**深度来自联动而非维度;LLM 只当嘴与裁判,代码管状态机与数值,两边界限清晰、不互相翻译。**

## 三铁律

1. **极简底层**:几个国势 + 几股势力 + 人物 + 危机,深度来自联动不来自维度。
2. **单层 LLM**:LLM 只当「嘴」与「裁判」,代码管状态机与数值,边界清晰、不互相翻译。裁判 LLM 给方向与档位(微/轻/中/大/极,定性)+ 叙事,代码做档位→数值的唯一映射,绝不反向从叙事里抠数字——这是 v2 区别于旧架构的核心。
3. **从第一刀就缝在一起**:信息不全 / 君命直贯 / 没有最优解 / 后果连锁。其中「耳目」国势把信息迷雾机制化——诛厂卫会掉它,皇帝从此看不清天下。

## 架构分层

| 模块 | 职责 |
| --- | --- |
| `state.py` | 状态机:国势 / 势力 / 人物 / 危机的 dataclass 模型。 |
| `engine.py` | 档位→数值的唯一映射:把裁判 LLM 的定性档位确定性地落成数值。 |
| `llm.py` | LLM 的两个介入点:召见(扮演大臣)+ 天下裁判(定性效果 + 邸报)。 |
| `content.py` | 垂直切片开局数据(《定魏》《辽东索饷》)。 |
| `present.py` | 终端表现层:开场白、御案展示、终局史评等文案。 |
| `play.py` | CLI 驱动循环。 |

## 运行

在项目根先载入 `.env`(`OPENAI_*` 配置),再以模块方式运行:

```sh
set -a; source .env; set +a

python -m v2.play           # 交互终端原型
python -m v2.smoke_play     # 非交互自检,打后端日志、确认 LLM 链路走通
```
