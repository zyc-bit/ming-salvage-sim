# 明末力挽狂澜

![明末力挽狂澜主页](docs/screenshots/home.png)

你是崇祯。

你知道十七年后北京城破，知道煤山那棵树在等你，也知道大明不是死于某一个敌人，而是死于国库空虚、辽东失血、流民四起、党争内耗、官僚敷衍、军队欠饷和一次次“朕已知悉”之后的无力。

但这一次，你可以亲自召见每一个人。

问户部银子去哪了，问兵部边军为什么又欠饷，问司礼监宫里谁在递话，问锦衣卫地方官到底有没有瞒灾。你可以下旨、任免、追责、赈灾、练兵、加税、清丈、议和、开战。大臣会给你建议，也会推诿、隐瞒、站队、阳奉阴违。你以为自己写下的是圣旨，真正落到地方时，可能已经变成另一件事。

这不是一款“选择 A/B/C”的历史问答游戏，而是一场围绕晚明国家机器的对话式政略模拟：你说什么、信谁、逼谁、放过谁，都会变成后续日月里的财政、军情、民变和朝局。

这里没有开局送神兵、没有天降忠臣、没有一键中兴。你能依靠的只有局势条、奏报、大臣嘴里的半真半假，以及自己的脑洞：怎么借力打力，怎么拆东墙补西墙，怎么把一句话说成一道能落地的旨。

## 为什么值得试

| 优点 | 说明 |
| --- | --- |
| 自定义 API Key，低成本长线游玩 | 推荐使用 OpenAI 兼容接口；主模型可配便宜快速模型，推演/打分可另配更强的 advanced model。实际成本取决于模型、缓存命中和游玩长度。 |
| 数值有落点，局势有推进 | 国库、内库、民心、皇威，加上各省民变、士绅阻力、军队欠饷、外部势力都会持续变化。它不是纯聊天游戏，而是每句话都要落回国家机器。 |
| 没有万能改革按钮 | 局势怎么推、资源怎么挪、人怎么用，全靠玩家自己拆局。工程、军务、制度和技术相关事项都要靠诏令、承办人与资源落地。 |
| 圆一个“自定义 P 社游戏”的梦 | 人物、事件、地区、军队、外部势力和提示词都能继续扩写。想把晚明改造成什么样，可以自己动手。 |

## 快速开始

环境要求：

- Python 3.11+
- `uv`
- Node.js 20.19+ 或 22.12+
- 一个可用于 AI 对话的 API Key

```bash
git clone https://github.com/zyc-bit/ming-salvage-sim.git
cd ming-salvage-sim

uv venv --python 3.11
source .venv/bin/activate
uv pip install -r requirements.txt

cd web
npm install
npm run build
cd ..

cp .env.example .env
```

编辑 `.env`，至少填入：

```bash
OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_MODEL=deepseek-v4-flash
```

启动网页游戏：

```bash
./start.sh --port 8010
```

打开 <http://127.0.0.1:8010>。

`start.sh` 会自动读取 `.env`，必要时构建前端，再启动 `web_app.py`。如果你已经构建过前端，可以用：

```bash
./start.sh --no-build --port 8010
```

也可以跑纯文本调试版。CLI 仍走较旧的月回合交互，主要用于快速调试内核，不是当前主体验：

```bash
set -a
source .env
set +a
python3 main.py
```

## 怎么玩

网页版按“每日临朝”推进：同一天内可以召见、致信、核定大臣拟旨、手写指令、颁诏；退朝后推进到下一日。第 30 日退朝时会额外生成月末总结。

每天开始，你会看到当前国势、在办局势、密令、通信和近日报告。月末总结会复盘这个月收了多少税，花了多少饷，哪里闹灾，谁在办差，哪些旨意产生了后续回响。

然后你开始召见大臣。人在京师的官员可以入殿召对；不在京师的人必须通过书信、诏书或密令沟通，往返按地区路程耗时。你可以直接问，也可以试探，可以让他拟旨，可以要求查账、查军、查地方、查宫里。不同职位、不同人物、不同派系能告诉你的东西不一样，也会有不同的私心。

![召见大臣](docs/screenshots/chat.png)

局势是你判断国家还能撑多久的核心依据。国库见底，说明再漂亮的改革也可能没钱执行；皇威太低，说明圣旨出了紫禁城就会被打折；某省动乱升高，说明地方已经不只是穷，而是在准备掀桌。比如你想给辽东补饷，钱可以从内库挪、从盐税借、从江南加派、从宗室禄米里抠，但每一种做法都会牵动不同盘面：边军欠饷可能补上，民心可能下滑，地方士绅阻力可能被点燃，灾区民变也可能更难压。

等你整理好诏令，颁诏后，京师能当场执行的事项会即时落数；发往外地的诏书会生成在途通信，抵达后再触发地方回奏。退朝时系统会做日终推演，处理自然变化、到期通信、密令核议和候选情势；月末再做总括。

后宫也是一条可经营的线。你可以下旨选妃，司礼监会从预设的秀女池里遴选几名呈上御览，附性情与才艺；你看中谁，再降诏册封她入宫。入宫之后召见妃嫔，除了闲话家常，还能调教——明确要她学一门技艺、改一种性子，都会写进她的永久记忆，往后召见便见变化。

进度随时存档，可多周目重开。

## 想做成什么

- 一个可以长期游玩的晚明皇帝模拟器，不只是“活到 1644”，而是让每条改革路线都有代价和回声。
- 一个真正围绕官僚系统运转的政略游戏：圣旨不是按钮，执行才是战场。
- 一个会记仇、会惯性、会自我恶化的国家机器：欠饷会拖垮军心，苛派会逼出民变，党争会吞掉改革。
- 一个半开放的历史沙盘：皇太极、流寇、灾荒、边镇、宗室、士绅、宦官、东林、阉党都会动，但不必完全照着历史死去。
- 一个没有金手指的脑洞实验场：没有标准答案，只有你能不能把有限资源、人物关系和局势压力玩出一条活路。
- 一个适合魔改的内容框架：人物、事件、地区、军队、外部势力、提示词都可以继续扩写。

## 已实现

| 模块 | 功能 | 亮点 |
|---|---|---|
| **核心玩法** | 日推进 + 月末总结 | 网页版每日临朝、退朝到次日，第 30 日额外生成月末总结；CLI 保留月回合调试入口 |
| | 大臣召见与远程通信 | 在京官员可召对；外地人物走书信、诏书或密令，按地区路程产生抵达/回奏延迟 |
| | 诏令流程 | 对话中形成草案 → 编辑/删除/批准 → 颁诏结算 |
| | 执行偏差 | 圣旨不一定按原意落地——钱不够、皇威低、派系作梗、路途遥远都会让结果走样 |
| **AI 驱动** | 日终邸报与月末总结 | 每日退朝生成日终推演，第 30 日生成月末总结，按章叙时局与圣旨回响 |
| | 事项推进 | 改革与危机立为可追踪事项，每月按惯性漂移，皇帝行动可加速/扭转/改变难度 |
| | **事件记忆** | 结算后自动提炼记忆卡（人物/地区/朝廷/外部势力），大臣下次召见时会读取旧事，让对话前后贯通；记忆按重要度自动衰减（importance 1–4设TTL，5永久保留） |
| | **推演记忆注入** | 结算前专用 agent 从诏书、当日事件和相关实体召回历史记忆，注入推演与打分，使邸报叙事前后贯通、档房定档更准 |

| | **即时回奏** | 召对、在京诏令和部分工具结果会即时推演落数，不等到月末才生效 |

## 配置

复制 `.env.example` 为 `.env` 后填写配置。

| 变量 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `OPENAI_API_KEY` | 是 | 无 | API Key |
| `OPENAI_BASE_URL` | 否 | `https://api.openai.com/v1` | API 地址，推荐 `https://api.deepseek.com` |
| `OPENAI_MODEL` | 否 | `gpt-4o-mini` | 模型名，推荐 `deepseek-v4-flash` |
| `OPENAI_TIMEOUT_SECONDS` | 否 | `180` | LLM 请求总超时秒数 |
| `OPENAI_CONNECT_TIMEOUT_SECONDS` | 否 | `60` | HTTP 连接超时秒数 |
| `OPENAI_READ_TIMEOUT_SECONDS` | 否 | `120` | 流式读取间隔超时秒数 |
| `OPENAI_TRUST_ENV` | 否 | `true` | 是否让 httpx 读取系统代理环境；接口被代理干扰时可设为 `false` |
| `OPENAI_ADVANCED_MODEL` | 否 | 空 | 推演/打分专用模型，空则复用主模型 |
| `OPENAI_ADVANCED_BASE_URL` | 否 | 空 | advanced model 专用 API 地址，空则复用 `OPENAI_BASE_URL` |
| `OPENAI_ADVANCED_API_KEY` | 否 | 空 | advanced model 专用 API Key，空则复用 `OPENAI_API_KEY` |
| `MING_SIM_DB` | 否 | `data/ming_sim.db` | 存档数据库路径 |
| `MING_SIM_SEED` | 否 | `7` | 随机种子 |
| `MING_SIM_START_YM` | 否 | 空 | 新存档起始年月，如 `1629.04` |
| `CLI_API_KEY` | 否 | 回退 `OPENAI_API_KEY` | probe/调试脚本用的 API Key 覆盖项；`main.py` 本身直接读取 `OPENAI_API_KEY` |
| `CLI_BASE_URL` | 否 | 回退 `OPENAI_BASE_URL` | probe/调试脚本用的 API 地址覆盖项；`main.py` 本身直接读取 `OPENAI_BASE_URL` |
| `CLI_MODEL` | 否 | 回退 `OPENAI_MODEL` | probe/调试脚本用的模型覆盖项；`main.py` 本身直接读取 `OPENAI_MODEL` |
| `PLAYTEST_API_KEY` | 否 | 回退 `OPENAI_API_KEY` | `scripts/play_as_emperor.py` 自动游玩脚本 API Key |
| `PLAYTEST_BASE_URL` | 否 | 回退 `OPENAI_BASE_URL` | `scripts/play_as_emperor.py` 自动游玩脚本 API 地址 |
| `PLAYTEST_MODEL` | 否 | 回退 `OPENAI_MODEL` | `scripts/play_as_emperor.py` 自动游玩脚本模型名 |
